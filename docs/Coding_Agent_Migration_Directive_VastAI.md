## Objective

Pivot the extension from Google Colab to Vast.ai as the primary automated compute backend. The final experience should be indistinguishable from normal Lumiverse image generation: I select a model/workflow and LoRA preset natively, press the existing generation button, and the extension starts or resumes a GPU, prepares required assets, connects securely, lets native generation run, saves the result natively and stops the instance after real inactivity. Do not create a second image generator or LoRA Studio.

These are configurable target preferences, not guaranteed offers. Show actual current quote, including stopped storage and network charges. Proposed max $0.20/hour and five-minute idle stop are editable defaults, not approved spend. Never rent above approved limits, auto-refill, destroy unrelated instances or blindly retry an ambiguous create. Track ownership and absolute deadlines durably. Default idle action STOP (not destroy). Separate explicit destruction with data-loss/retention warning. Confirm stop through provider API and report uncertainty honestly.
- Automatic start must happen on **normal native generation request**, not on setup browsing, catalog/health checks or merely saving preferences. Use single-flight admission and active/queued/download/output leases, then idle shutdown from last real work. Keep warm while legitimate work is pending, not via fake activity. Reconcile state on crashes, Space sleep/restart and endpoint changes. Validate an independent instance-scoped watchdog or provider safety mechanism, without exposing my master key to a GPU host; if that fails, block unattended mode and report.
